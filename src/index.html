How this page stays current

  1. The calls live in data files in the site's GitHub repository. GitHub rebuilds the page whenever they change, and the host publishes the result.
  2. Every Monday an automated check re-reads each call's funder page and UKRI's new-opportunities feed. It proposes date changes and new calls for a person to approve. Changes a funder makes between Mondays won't show until the next check.
  3. Each card shows when it was last checked. Anything not checked for 30 days is flagged.

Always confirm on the funder's own page before you bid.
